# RingCentral to amoCRM Integration

## Overview

This ASP.NET Core 9.0 application provides a bi-directional integration between RingCentral and amoCRM systems. It automatically synchronizes SMS messages and call logs from RingCentral to amoCRM contact records, creating notes in the CRM system for better customer communication tracking.

## Features

### 1. SMS Integration
- **Real-time WebHook**: Receives SMS notifications from RingCentral via WebHooks
- **Automatic Note Creation**: Creates notes in amoCRM leads when SMS messages are received
- **Bidirectional Support**: Handles both inbound and outbound SMS messages
- **Phone Number Matching**: Automatically finds related leads in amoCRM by phone number

### 2. Call Log Integration
- **Periodic Polling**: Fetches call logs from RingCentral API every 2 minutes
- **Call Recording Upload**: Downloads call recordings from RingCentral and uploads them to amoCRM Drive
- **Detailed Call Notes**: Creates comprehensive notes with call duration, direction, participants, and recording links
- **Automatic Lead Matching**: Links call events to existing leads based on caller phone number

### 3. Subscription Management
- **Automatic Renewal**: Renews RingCentral WebHook subscriptions every 5 days (subscriptions expire after 7 days)
- **SMS Event Subscription**: Maintains active subscription for SMS message events
- **Health Monitoring**: Logs subscription status and handles failures gracefully

## System Components

### Controllers

#### 1. `RingCentralWebHookController`
**Purpose**: Handles incoming WebHook requests from RingCentral

**Key Endpoints**:
- `POST/GET /api/RingCentralWebHook/webhook` - Main SMS WebHook endpoint
- `POST /api/RingCentralWebHook/webhook/call` - Call event WebHook (optional)
- `GET /api/RingCentralWebHook/Subscriptions` - List active subscriptions
- `POST /api/RingCentralWebHook/Delete subscription` - Delete a subscription

**Responsibilities**:
- Validate incoming WebHook requests (validation token handshake)
- Parse SMS notification payloads
- Extract sender/receiver information
- Trigger amoCRM note creation

#### 2. `AmoCrmController`
**Purpose**: Handles OAuth2 authorization flow for amoCRM

**Key Endpoints**:
- `GET /oauth/callback` - OAuth2 callback endpoint for initial authorization

**Responsibilities**:
- Exchange authorization code for access/refresh tokens
- Store tokens securely in configuration

### Services

#### 1. `AmoCrmService`
**Purpose**: Core business logic for amoCRM integration

**Key Methods**:

```csharp
// Authentication & Token Management
Task InitializeAsync()

Task RefreshTokensAsync(string refreshToken)

Task CreateCallNoteAsync(long leadId, CallLogRecord record, string recordingUrl)

// File Operations
Task<string> UploadCallRecordingAsync(string recordingId, string callId)
```

**Features**:
- Automatic token refresh with retry logic
- Exponential backoff for failed requests
- SSL/TLS error handling
- Token persistence to configuration file

**Purpose**: Manages RingCentral WebHook subscriptions

**Features**:
- Creates WebHook subscriptions for SMS events
- Deletes old subscriptions before creating new ones
- Configurable subscription expiration (6 days)
- Automatic authorization handling

## Setup and Configuration

### Prerequisites

1. **RingCentral Account**
   - Developer account with API access
   - JWT credentials (Client ID, Client Secret, JWT token)
   - WebHook-capable endpoint (public HTTPS URL)

2. **amoCRM Account**
   - Integration created in amoCRM admin panel
   - OAuth2 credentials (Client ID, Client Secret)
   - Redirect URI configured

3. **Environment**
   - .NET 9.0 SDK installed
   - HTTPS certificate (for WebHook validation)
   - Public domain or ngrok for development

### Configuration File

Edit `appsettings.json`:

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  
  "Credentials": {
    "CID": "your_ringcentral_client_id",
    "CS": "your_ringcentral_client_secret",
    "JWT": "your_ringcentral_jwt_token",
    "URL": "https://platform.ringcentral.com",
    "RedirectUri": "https://your-domain.com/rc2amocrm"
  },
  
  "AmoCrm": {
    "ClientId": "your_amocrm_client_id",
    "ClientSecret": "your_amocrm_client_secret",
    "RedirectUri": "https://your-domain.com/oauth/callback",
    "Subdomain": "your_subdomain",
    "RefreshToken": "",
    "AccessToken": ""
  }
}
```

### Initial Setup Steps

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd RingCentral_amoCRM
   ```

2. **Configure credentials**
   - Edit `appsettings.json` with your credentials
   - Ensure `RedirectUri` matches your deployment URL

3. **Build the application**
   ```bash
   dotnet build
   ```

4. **Authorize amoCRM** (First-time only)
   - Navigate to: `https://your-subdomain.amocrm.ru/oauth?client_id={ClientId}&redirect_uri={RedirectUri}&response_type=code`
   - Authorize the integration
   - The application will automatically exchange the code for tokens and save them

5. **Run the application**
   ```bash
   dotnet run
   ```

6. **Verify setup**
   - Check logs for successful subscription creation
   - Test SMS webhook: `POST https://your-domain.com/rc2amocrm/api/RingCentralWebHook/webhook`
   - Monitor call log polling in logs

## API Endpoints

### RingCentral WebHook Endpoints

#### `POST/GET /api/RingCentralWebHook/webhook`
**Purpose**: Main SMS WebHook endpoint

**Request Headers**:
- `Validation-Token` (optional, only on first request)

**Request Body** (POST):
```json
{
  "uuid": "string",
  "event": "/restapi/v1.0/account/{accountId}/extension/{extensionId}/message-store/instant?type=SMS",
  "timestamp": "2025-01-01T00:00:00.000Z",
  "subscriptionId": "string",
  "body": {
    "id": "string",
    "from": {
      "phoneNumber": "+1234567890",
      "name": "John Doe"
    },
    "to": [{
      "phoneNumber": "+0987654321",
      "name": "Jane Smith"
    }],
    "type": "SMS",
    "direction": "Inbound",
    "subject": "Message text here"
  }
}
```

**Response**:
- `200 OK` - Successfully processed
- `201 Created` - Note added to amoCRM

#### `GET /api/RingCentralWebHook/Subscriptions`
**Purpose**: List all active RingCentral subscriptions

**Response**:
```json
[
  {
    "id": "subscription-id",
    "uri": "https://platform.ringcentral.com/...",
    "eventFilters": [
      "/restapi/v1.0/account/~/extension/12345/message-store/instant?type=SMS"
    ],
    "expirationTime": "2025-01-06T00:00:00.000Z",
    "deliveryMode": {
      "transportType": "WebHook",
      "address": "https://your-domain.com/webhook"
    }
  }
]
```

#### `POST /api/RingCentralWebHook/Delete subscription`
**Purpose**: Delete a specific subscription

**Query Parameters**:
- `subscriptionId` (string, required)

**Response**:
- `200 OK` - Deleted successfully
- `500 Internal Server Error` - Deletion failed

### amoCRM OAuth Endpoints

#### `GET /oauth/callback`
**Purpose**: OAuth2 callback for initial authorization

**Query Parameters**:
- `code` (string, required) - Authorization code from amoCRM

**Response**:
- `200 OK` - "? Интеграция amoCRM успешно авторизована и токены сохранены!"
- `400 Bad Request` - Missing or invalid code
- `500 Internal Server Error` - Token exchange failed

### Utility Endpoints

#### `GET /api/RingCentralWebHook/Messages`
**Purpose**: Retrieve messages for a specific extension (debugging)

#### `GET /api/RingCentralWebHook/Users`
**Purpose**: List all RingCentral extensions (debugging)

   ```bash
   docker build -t ringcentral-amocrm-integration .
   ```

2. **Run container**:
   ```bash
   docker run -d \

     -v /path/to/appsettings.json:/app/appsettings.json \
   ```

### IIS Deployment

1. **Publish the application**:
   ```bash
   dotnet publish -c Release -o ./publish
   ```

2. **Configure IIS**:
   - Create a new site or application
   - Point to the `publish` folder
   - Install .NET 9.0 Hosting Bundle
   - Configure HTTPS binding with valid certificate

3. **Application Pool Settings**:
   - .NET CLR Version: No Managed Code
   - Managed Pipeline Mode: Integrated
   - Identity: Custom account with file permissions

### Linux/systemd Deployment

1. **Create systemd service file** (`/etc/systemd/system/ringcentral-amocrm.service`):
   ```ini
   [Unit]
   Description=RingCentral to amoCRM Integration
   After=network.target

   [Service]
   Type=notify
   User=www-data
   WorkingDirectory=/var/www/ringcentral-amocrm
   ExecStart=/usr/bin/dotnet /var/www/ringcentral-amocrm/RingCentral_amoCRM.dll
   Restart=always
   RestartSec=10
   SyslogIdentifier=ringcentral-amocrm

   [Install]
   WantedBy=multi-user.target
   ```

2. **Enable and start**:
   ```bash
   sudo systemctl enable ringcentral-amocrm
   sudo systemctl start ringcentral-amocrm
   sudo systemctl status ringcentral-amocrm
   ```

## Troubleshooting

### Common Issues

#### 1. WebHook Validation Fails
**Symptom**: RingCentral shows subscription as "Invalid" or "Disabled"

**Solutions**:
- Ensure your endpoint is publicly accessible via HTTPS
- Check that `Validation-Token` header is echoed back correctly
- Verify no firewall blocks incoming RingCentral IPs
- Test with: `curl -H "Validation-Token: test123" https://your-domain.com/webhook`

#### 2. amoCRM Token Refresh Fails
**Symptom**: Logs show "Failed to refresh amoCRM tokens"

**Solutions**:
- Verify `ClientId`, `ClientSecret`, and `RefreshToken` in `appsettings.json`
- Check that `RedirectUri` matches the one configured in amoCRM integration
- Ensure TLS 1.2 is enabled on your server
- Re-authorize the integration by visiting the OAuth URL

#### 3. Call Logs Not Appearing
**Symptom**: SMS works but calls don't create notes

**Solutions**:
- Check `CallLogPollingService` logs for errors
- Verify RingCentral JWT token has `ReadCallLog` permission
- Ensure phone numbers in call logs match format in amoCRM (with/without +)
- Check that leads exist in amoCRM for the phone numbers

#### 4. SSL/TLS Certificate Errors
**Symptom**: "SSL connection could not be established"

**Solutions**:
- Install valid SSL certificate for production
- For development, the code includes a certificate validation bypass (remove in production)
- Update `HttpClientHandler` SSL protocols if needed

#### 5. Subscription Expires Unexpectedly
**Symptom**: SMS stops working after a few days

**Solutions**:
- Check `SubscriptionHostedService` logs for renewal errors
- Verify RingCentral JWT token hasn't expired
- Manually trigger renewal via `/api/RingCentralWebHook/Subscriptions` endpoint
- Restart the application to force re-creation

## Security Considerations

1. **Credentials Storage**:
   - Never commit `appsettings.json` with real credentials to version control
   - Use environment variables or Azure Key Vault in production
   - Rotate JWT tokens and OAuth secrets regularly

2. **HTTPS Enforcement**:
   - Always use HTTPS for WebHook endpoints
   - RingCentral requires valid SSL certificates for production

3. **Token Security**:
   - Refresh tokens are automatically updated and persisted
   - Access tokens are stored in memory and refreshed automatically
   - Consider encrypting stored tokens at rest

4. **Rate Limiting**:
   - RingCentral API has rate limits (check documentation)
   - Call log polling every 2 minutes is within safe limits
   - Implement exponential backoff for failures (already done)
